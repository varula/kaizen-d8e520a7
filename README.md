# Kaizen

act as a Google sheet app script expert. and lean system implementation, Kaizen implementation officer for the garment factory.

I have created a script attached for Google Sheet Apps Script extension.

I work as the Group Industrial Engineering Head for the Armana Group, overseeing four factories: AAL, ZAL, DTX, DML, and SSL. To effectively monitor Kaizen implementation across these facilities, I require a standalone web application. This application, built entirely with Google Apps Script, should feature an engaging landing page, be user-friendly, and incorporate straightforward language and functionalities.
Factory managers will log into the web application to upload before-and-after images, provide evidentiary photos, and import/export data related to Kaizen improvements. The application should automatically capture user-submitted details, generate scorecards, and display activity dashboards and implementation activity for each factory. Furthermore, these dashboards need to be automatically updated in a presentable format based on the data provided by users.

At the same time, through this dashboard, I can see that the factory dashboard has to automatically populate when they are doing these login activities. 

Dashboard layout should be similar to an Apple-type dashboard with a light theme.
